# 01 — Foundations: Linear Algebra for Deep Learning

Day 1 of the DL for Data Science series.

## Contents
- `01_linear_algebra_basics.ipynb` — Scalars, vectors, matrices, tensors, dot products, matrix multiplication, transpose, inverse, broadcasting, and the Pandas → NumPy bridge

## Key Concepts
- A neuron's output = dot product of inputs and weights + bias
- A layer's output = matrix multiplication of a batch with weights
- Pandas is for exploring/cleaning data; NumPy is what the model actually computes on

## How to Run
```bash
pip install numpy pandas jupyter
jupyter notebook 01_linear_algebra_basics.ipynb
```
